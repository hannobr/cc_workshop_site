01  ·  How Claude works

Gather, act, verify. Repeat.

A short read on the cycle Claude Code runs on every prompt.

~5 min · Reading only, no typing yet

Source anthropic.skilljar.com/claude-code-101 ↗

A

What is agentic AI?

In Laurence Moroney's definition, agentic AI is four steps in a loop:

"The first of these steps is to understand intent. [...] The second part then is planning. [...] Once it's then figured out that plan, then it uses the tools to get to a result. [...] the fourth and final step is to reflect on that result. [...] Did we meet the intent? Yes or no? If we didn't, then go back to that loop."

Source L. Moroney (guest), Stanford CS230 Autumn 2025, Lecture 9, at 1:02:07
B

What is a coding agent?

A coding agent has two components. The model reasons and decides the next step. The harness, Claude Code here, wraps it with tools, permissions, context, and an execution environment, and runs the loop between them. The loop is what makes the pair an agent; your prompt is what starts it. Give the harness repo-shaped tools (files, shell, git) and it's a coding agent.

Source code.claude.com/docs/en/how-claude-code-works ↗

C

Claude Code is a coding agent

Claude Code runs that cycle as three phases: gather context, take action, verify results. Every prompt kicks it off, and Claude repeats it until the result satisfies what you asked for. Planning is the deciding between steps; reflect is verify, the check against your prompt.

Gather is reading: files, docs, command output. Act is changing: edits, commands, API calls. Verify checks the result against your prompt; a miss loops back with what was learned.

D

Your interrupts

Claude streams every action to your terminal as it runs. When something looks off, step in.

Esc

Interrupts the run. Tell Claude what to do instead of letting a wrong answer finish.

Esc Esc

Opens /rewind. Rewinding past a mistake and re-prompting with what you learned beats stacking corrections on a wrong run.

/btw

A side question mid-run, answered without stopping the work.
