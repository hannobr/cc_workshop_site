02  ·  Setup

From install to first session in five minutes.

Get Claude Code running in your workshop folder with the right model selected. By the end you'll be at a live Claude Code prompt, ready for the next steps.

~5 min · 5 steps

Heads up

We're using the Claude Code CLI today.

The whole workshop runs in your terminal. VS Code and IntelliJ are also installed on your Mac mini, but everything we run together goes through the Claude Code CLI.

Term

Auto mode: the mode these minis are set up to start in; check your status bar reads auto mode on, as in the terminal below, and raise a hand if it says something else. Claude reads and edits files in your project and runs routine commands without stopping to ask; a built-in safety check still flags anything risky. Shift+Tab cycles the other modes: manual, accept edits, and plan. Plan mode proposes before it touches anything; steps 04, 05 and 07 use it.

01

Start

Launch a terminal

Two options:
  • Press ⌘ + Space, type Terminal, press Return.
  • Launch a terminal in your IDE.
⌘+Space type Terminal, then Return ↵
02

Set up the folder

cd into your workshop folder and git init

The folder ~/workshop is already on your mini, but it is not a git repo yet. git init makes it one, so the first commit on step 04 has somewhere to land.
$ cd ~/workshop then Return ↵
$ git init then Return ↵
Initialized empty Git repository in /Users/workshop/workshop/.git/
03

Start the assistant

Run Claude

Your mini is already signed in, so this drops straight into a session. At the trust prompt, arrow to ‘Yes, I trust this folder’ and press Return.
$ claude then Return ↵
04

Select your model

Open the model picker with /model

Type /model and press Return. A selection panel will appear.
› /model then Return ↵
05

Final check

Set Opus · High effort

Pick ‘Opus’. Effort must read ‘High effort’: arrow left or right until it does, then Return to confirm.
