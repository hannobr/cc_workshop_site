Customise the harness  ·  MCP

MCP.

Tools and data from outside Claude Code, plugged into the session. The rule of thumb: if you keep copying things into the chat from another system, connect that system instead.

~4 min · Reference; lives in .mcp.json

A · What it is

A socket board for your other systems.

MCP, the Model Context Protocol, is an open standard for connecting AI applications to external systems. Its own documentation calls it “a USB-C port for AI applications”. A server exposes tools; you plug it into the session; Claude reads and acts on that system directly instead of on what you pasted.

B · When to use it

When the answer lives in another system.

Connect a server when you find yourself copying data into the chat from a tracker, a dashboard or a database.

Reach for MCP

  • Implementing from tickets: let Claude read the issue rather than your paraphrase of it.
  • Querying a database in plain English, against a read-only user.
  • Monitoring and error data, so a fix starts from the real trace.
  • Designs and documents held in a tool that is not the repo.
  • Cross-tool workflows that would otherwise be you, moving text between tabs.

Reach for something else

  • A job a CLI already does. For GitHub, gh is usually simpler than a server.
  • A server you have not read. Its tools run with your session's reach.
  • Credentials in a committed .mcp.json. Use environment expansion instead.
  • A write-capable database user, when read-only would do.

C · A real example

Ask your analytics database a question.

A committed project config that carries the shape and none of the secrets.

  1. 01You export ANALYTICS_DSN in your shell, pointing at the read-only user.
  2. 02First session in the repo, Claude Code asks you to approve the project server. You say yes once.
  3. 03/mcp shows db as connected.
  4. 04You ask “show me the schema for the orders table” and get an answer from the database, not from a guess.

Two limits worth knowing before you wire up something chatty. Tool output over roughly 10,000 tokens warns, and 25,000 is the default ceiling. And tool search is on by default, so connecting a big server no longer floods your context: only the tool names load until one is used.
