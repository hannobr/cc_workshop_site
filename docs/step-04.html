04  ·  Build

Build your own idea.

Build what you came to build, at your own pace. Everything below is reference: take what helps and leave the rest.

Hint

Begin by asking Claude Code to interview you about your idea, one question at a time.

Plan mode, then auto mode

Start in plan mode, then run the plan in auto mode. Shift+Tab switches modes and the status bar names the one you are in [1].

You do not have to plan everything. If the change is small, ask Claude for it directly in auto mode [3].

Give Claude a way to check itself

Without a check Claude can run on its own, you are the only feedback loop, and every mistake waits for your attention [3].

"The most important tip for using Claude Code is: give Claude a way to verify its output. Once you do that, Claude will iterate until the result is great."

Source B. Cherny, creator of Claude Code, on X, 30 March 2026

Boris Cherny gives three examples of such a check [4]. Your idea may need a different one.

  • Unit tests Claude runs them, reads what failed and goes again, without waiting for you to look.
  • The Chrome extension Claude opens the page it just built, looks at the result and fixes what does not match.
  • A device simulator Claude taps the flow through on a phone and sees where it breaks.

The Chrome extension is not installed on the workshop machines. The playwright-cli skill is, and it does the same job: Claude opens the page it built, takes a screenshot and reads the result back. Give Claude one check it can run without you.

Two moves worth knowing

Neither is on a schedule. Reach for them when the session gives you a reason to.

  1. Clear between tasks A session carries everything you did earlier, and all of it stays in the context window you watched on step 03. When you switch to something unrelated, clear it: what is left over fills the window and can pull the next answer off course [3].
    › /clear then Return ↵
  2. Send the review to a subagent A subagent starts in a fresh, isolated context window [2]. It does not see your conversation, so it reads your work the way someone who never sat through the session reads it, and it is not defending a choice it made an hour ago. Name what it reads: the plan, the last change, one file.
    › Launch a subagent for an adversarial review of the plan. then Return ↵
