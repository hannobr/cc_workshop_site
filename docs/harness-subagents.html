Customise the harness  ·  Subagents

Subagents.

A second Claude with its own context window, its own system prompt and its own tool list. It does the noisy part of the work somewhere else and hands back a summary.

~4 min · Reference; lives in .claude/agents/

A · What they are

A second window, doing the noisy part.

A subagent is a markdown file with frontmatter: a name, a description saying when to delegate, and optionally the tools, the model and the permissions it runs under. The body of the file is its system prompt. It works in a context window of its own and hands back a summary.

B · When to use them

When you want the work, not the transcript.

The question to ask is whether you need to watch the work happen. If you only need its verdict, delegate it.

Reach for a subagent

  • Verbose, self-contained work: run the suite, read the logs, come back with what failed.
  • A read-only reviewer that physically cannot edit what it is reviewing.
  • Parallel investigations that do not need to talk to each other.
  • Cost control: route mechanical work to a cheaper model with model.
  • A repeated role your team should share, committed in the repo.

Reach for something else

  • Work needing back and forth. The summary is all you get back.
  • Phases that share a lot of context. Handing it over costs more than it saves.
  • A quick, targeted change. Delegation has real latency.
  • Something that must run every time regardless. That is a hook.
  • A procedure you invoke yourself. That is a skill.

C · A real example

A verifier that cannot touch the code.

The agent step 06 of this workshop has you write. Its whole argument is the tool list.

  1. 01Claude finishes the build and claims it satisfies the spec.
  2. 02The verifier is delegated to, in a fresh context window with four tools.
  3. 03It runs the check, reads whatever it needs, and burns its own window on the output.
  4. 04You get PASS, FAIL or BLOCKED and a short report. Your window never held the log.

Fewer tools is the design. Every tool you leave out is a class of mistake the agent cannot make, and a reason to trust the answer it gives you.
